## v2.7.7 — Telegram Desktop, авто-админ, все стратегии

### Telegram Desktop (главное)
- **Исправлен мост tg-ws-proxy** — секрет MTProto был 31 символ вместо 32, мост падал и порт 1443 не открывался
- **Автопоиск Telegram.exe** — через процесс (QueryFullProcessImageName), реестр Windows и стандартные папки; в логе: `найден — C:\...\Telegram.exe`
- **Прокси один раз за сессию** — больше не всплывает «Подключить прокси» каждые 20 секунд
- **Автоклик «Подключить прокси»** — поддержка Qt-кнопок и текста «Подключить прокси»
- **Порядок запуска** — сначала winws (обход), потом мост; без браузера и без ручной настройки прокси
- **Hosts для Telegram** — 36+ доменов (web + desktop), как у Discord

### Все стратегии (Multidisorder, FakeSplit, TCP Segmentation, OOB)
- YouTube, Discord и Telegram работают **во всех встроенных пресетах**
- Hosts и мост Telegram включаются по **содержимому** пресета, а не только по названию «YouTube + Discord + Telegram»
- Обновлены описания стратегий в списке

### Запуск от администратора
- **Автоматический запрос UAC** при старте — не нужно вручную «Запуск от имени администратора»
- Двойной клик по `ZapretUI.exe` → подтвердить UAC → готово

### Прочее
- Миграция настроек (SettingsVersion 4) — исправление секрета MTProto у существующих пользователей
- Улучшенные сообщения в журнале движка

## Установка / обновление
1. Скачайте `ZapretUI-v2.7.7.zip`
2. Распакуйте в любую папку
3. Запустите `ZapretUI.exe` (UAC спросит сам)
4. Выберите пресет → **Включить обход**

## Тест
- YouTube, Discord, веб-Telegram — через hosts + winws
- Telegram Desktop — через мост 127.0.0.1:1443 (автоматически)
